# Overview

As a software engineer, I am building a strong foundation by making sure my development tools work together smoothly, from writing code to publishing it online. This project is my first step in setting up that workflow.

Hello World is a small Python program that prints a greeting to the screen. It prints "Hello World!" and then a personal greeting from Tanzania.

My purpose in writing this software was to confirm that my development environment works, and to practice the full cycle of writing code, documenting it, recording a demo, and publishing it to a public GitHub repository. I will use the same process for every project I build.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I used Visual Studio Code to write and run the program, Git to track the code, and GitHub to publish it online.

The program is written in Python 3.
